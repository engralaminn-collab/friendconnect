    30→    30→## Socket.io Events (server <-> client)
    31→    31→Client → server:
    32→    32→- `RT.MESSAGE_SEND` `{ tempId?, receiverId, content, type?, fileUrl?, fileName?, fileSize?, mimeType? }` → ack `{ ok, message, tempId }`. Server persists + emits `message:new` to both rooms. Auto-marks DELIVERED if recipient online.
    33→    33→- `RT.MESSAGE_SEEN` `{ messageId }` → server marks SEEN, emits `message:status` `{ id, status:'SEEN' }` to sender.
    34→    34→- `RT.TYPING` `{ receiverId, isTyping }` → server emits `typing:indicator` `{ userId, isTyping }` to receiver.
    35→    35→- `RT.GROUP_MESSAGE_SEND` `{ tempId?, groupId, content, type?, fileUrl?, fileName?, fileSize?, mimeType? }` → ack `{ ok, message, tempId }`. Server persists + emits `group:message:new` to all members (message includes `sender` with profile).
    36→    36→- Call signaling: `RT.CALL_OFFER` `{ targetUserId, type, sdp }`, `RT.CALL_ANSWER` `{ targetUserId, sdp }`, `RT.CALL_ICE` `{ targetUserId, candidate }`, `RT.CALL_RINGING` `{ targetUserId }`, `RT.CALL_REJECT` `{ targetUserId }`, `RT.CALL_END` `{ targetUserId }`.
    37→    37→Server → client:
    38→    38→- `message:new` (full message object: id, senderId, receiverId, groupId, content, type, fileUrl, fileName, fileSize, mimeType, status, createdAt)
    39→    39→- `message:status` `{ id, status }`
    40→    40→- `typing:indicator` `{ userId, isTyping }`
    41→    41→- `group:message:new` (message object + `sender: { id, name, profile: { photoUrl } }`)
    42→    42→- `presence` `{ userId, online }`
    43→    43→- `call:incoming` `{ callerId, type?, sdp?, ringing? }` (from incoming offer or ringing ping)
    44→    44→- `call:sdp` `{ kind: 'answer', sdp, from }`
    45→    45→- `call:ice-candidate` `{ candidate, from }`
    46→    46→- `call:ended` `{ reason, by, from }`

    48→    48→## REST API endpoints (all require auth except auth/*)
    49→    49→- Auth: `POST /api/auth/register|login|logout|forgot|verify-otp|reset-password`, `GET /api/auth/me`, `GET /api/auth/token`.
    50→    50→- Users: `GET /api/users/search?q=`, `GET /api/users/:id`, `PUT /api/users/me` (body fields: name, username, photoUrl, bio, phone, location, birthday, education, work, profileVisibility, messagePermission, callPermission).
    51→    51→- Friends: `GET /api/friends` (list), `POST /api/friends` `{ action: 'request'|'accept'|'reject'|'remove'|'block'|'unblock', targetId }`, `GET /api/friends/requests` `{ incoming[], outgoing[] }`, `GET /api/friends/blocked`.
    52→    52→- Messages: `GET /api/messages/conversations` → `{ conversations: [{ id, username, name, photoUrl, lastMessage, unread }] }`, `GET /api/messages?userId=ID` or `?groupId=ID` → `{ messages: [...] }` (also marks incoming 1:1 as SEEN).
    53→    53→- Groups: `GET /api/groups`, `POST /api/groups` `{ name, description?, memberIds?, photoUrl? }`, `GET /api/groups/:id`, `GET /api/groups/:id/messages`, `POST/DELETE /api/groups/:id/members`.
    54→    54→- Calls: `GET /api/calls` (history), `POST /api/calls` `{ action:'start', receiverId, type:'audio'|'video' }` → `{ call: { id } }`, `POST /api/calls` `{ action:'end', callId, status?, duration? }`.
    55→    55→- Notifications: `GET /api/notifications` `{ unread, notifications[] }`, `POST /api/notifications` `{ all?: true } | { id }`.
    56→    56→- Setup: `POST /api/setup` seeds demo accounts (aria/bilal/carla @friendconnect.app, password password123).
